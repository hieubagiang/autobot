# AI Docs (Clean Layer)

This folder is an AI-first, stable layer built from `docs/ref`.

## Entry files
- `knowledge.json`: main machine-readable entrypoint
- `chapters_index.json`: lightweight chapter map
- `chapters/chapter_01.txt` ... `chapters/chapter_07.txt`: canonical chapter files (ASCII filenames)

## Notes
- Source of truth remains in `docs/ref`.
- This layer exists to improve retrieval stability for agents/tools.
